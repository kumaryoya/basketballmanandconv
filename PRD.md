# Planning Guide

A friendly chat application where users can have conversations with a cheerful basketball character mascot, with all responses generated by AI to create engaging, personality-driven interactions.

**Experience Qualities**: 
1. **Playful** - The interface should feel fun and energetic, matching the friendly basketball character's personality
2. **Conversational** - Smooth, natural chat flow that feels like talking to a real friend
3. **Delightful** - Small animations and thoughtful details that bring joy to the interaction

**Complexity Level**: Light Application (multiple features with basic state)
This is a chat interface with message history, AI generation, and character personality - straightforward functionality with engaging presentation.

## Essential Features

### Chat Message Display
- **Functionality**: Shows conversation history between user and basketball character
- **Purpose**: Creates context and continuity in the conversation
- **Trigger**: Automatically displays on load with any saved messages
- **Progression**: App loads → Messages render from oldest to newest → Auto-scroll to latest → User can scroll through history
- **Success criteria**: Messages display clearly with visual distinction between user and character, scroll works smoothly

### Send Message
- **Functionality**: User types and sends messages to the character
- **Purpose**: Core interaction mechanism for the chat
- **Trigger**: User types text and presses Enter or clicks send button
- **Progression**: User types message → Presses send → Message appears in chat → AI generates response → Character response appears
- **Success criteria**: Messages send instantly, input clears, character responds within 2-3 seconds

### AI Response Generation
- **Functionality**: Generates character responses using spark.llm with basketball mascot personality
- **Purpose**: Creates dynamic, engaging conversations that feel authentic to the character
- **Trigger**: Immediately after user sends a message
- **Progression**: User message received → Loading indicator shows → AI generates response with character personality → Response appears in chat
- **Success criteria**: Responses feel in-character, are contextually relevant, and arrive smoothly

### Conversation Persistence
- **Functionality**: Saves chat history using useKV
- **Purpose**: Maintains conversation context across sessions
- **Trigger**: Automatically saves after each message exchange
- **Progression**: Message sent/received → Conversation state updates → useKV persists data → User can close/reopen app with history intact
- **Success criteria**: Conversation history survives page refresh

### Clear Conversation
- **Functionality**: Allows user to start fresh conversation
- **Purpose**: Gives control to reset and start new topics
- **Trigger**: User clicks clear/reset button
- **Progression**: User clicks clear → Confirmation prompt → User confirms → Chat history clears → Fresh greeting appears
- **Success criteria**: History clears completely, new conversation starts naturally

## Edge Case Handling

- **Empty Input**: Send button disabled when input is empty, prevents blank messages
- **Long Messages**: Text area expands vertically, character responses break into natural paragraphs
- **API Failures**: Show friendly error message, allow retry without losing user's message
- **Very Long Conversations**: Scroll performance remains smooth, older messages can be scrolled to
- **Rapid Messages**: Prevent sending new message while AI is generating response

## Design Direction

The design should feel energetic and friendly like a sports mascot - warm orange tones, rounded shapes, and bouncy interactions. Think of a friendly basketball coach or teammate cheering you on. The character's playful personality should shine through in both the visual design and conversation style.

## Color Selection

Basketball-inspired palette with warm oranges and energetic reds, creating a sporty yet friendly atmosphere.

- **Primary Color**: Basketball Orange `oklch(0.72 0.15 45)` - Represents energy, friendliness, and directly connects to the basketball character
- **Secondary Colors**: 
  - Court Red `oklch(0.55 0.20 25)` for accents matching the character's shorts and shoes
  - Warm Cream `oklch(0.95 0.02 75)` for backgrounds, creating a warm canvas feel like the character image
- **Accent Color**: Bright Orange `oklch(0.75 0.18 50)` for interactive elements and character messages, creating energy and drawing attention
- **Foreground/Background Pairings**: 
  - Primary Orange (oklch(0.72 0.15 45)): White text (oklch(1 0 0)) - Ratio 5.2:1 ✓
  - Cream Background (oklch(0.95 0.02 75)): Dark Brown text (oklch(0.25 0.05 40)) - Ratio 11.8:1 ✓
  - Accent Orange (oklch(0.75 0.18 50)): Dark Brown text (oklch(0.25 0.05 40)) - Ratio 6.1:1 ✓

## Font Selection

Typography should feel friendly and approachable with a slight sporty energy - modern sans-serif that's easy to read in chat format.

- **Typographic Hierarchy**: 
  - Character Name: Freddy Grotesque Bold/18px/normal spacing - Fun, friendly header
  - User Messages: Inter Regular/15px/normal spacing - Clean, readable
  - Character Messages: Quicksand Medium/15px/relaxed spacing - Warmer, friendlier feel
  - Input Field: Inter Regular/15px/normal spacing - Familiar typing experience
  - Timestamps: Inter Regular/12px/wide spacing - Subtle, unobtrusive

## Animations

Animations should feel bouncy and energetic like a basketball, reinforcing the character's personality while keeping the chat functional.

- Message entrance: Gentle slide-up with slight bounce (spring physics) for new messages
- Character typing indicator: Bouncing dots that feel playful
- Send button: Scale pulse on hover, satisfying press animation on click
- Character avatar: Subtle breathing animation (scale) when character is "thinking"
- Scroll behavior: Smooth auto-scroll to new messages with easing

## Component Selection

- **Components**: 
  - Card for chat container with subtle shadow for depth
  - ScrollArea for message list with smooth scrolling
  - Input + Button for message composition
  - Avatar for character display with online status indicator
  - Badge for potential message timestamps
  - Separator for date dividers in long conversations
  - Alert for error states
  
- **Customizations**: 
  - Custom message bubbles (user: right-aligned with subtle blue-gray, character: left-aligned with orange gradient)
  - Character avatar with bouncing animation state
  - Typing indicator component with animated dots
  
- **States**: 
  - Send button: Disabled (muted) when input empty, hover with scale, active with press animation, loading with spinner
  - Input: Focus state with orange ring, disabled during AI response
  - Messages: Entrance animation, hover state showing timestamp
  - Clear button: Destructive variant, confirmation dialog before action
  
- **Icon Selection**: 
  - PaperPlaneRight for send action
  - Trash for clear conversation
  - ChatCircleDots for character thinking/typing
  - SmileyWink for character personality accent
  
- **Spacing**: 
  - Message bubbles: p-3 (12px padding)
  - Chat container: p-6 (24px padding)
  - Message gap: gap-4 (16px between messages)
  - Input group: gap-2 (8px between input and button)
  
- **Mobile**: 
  - Single column layout maintained
  - Input area fixed at bottom with safe-area padding
  - Character avatar slightly smaller (40px vs 48px)
  - Font sizes reduce by 1px for comfortable mobile reading
  - Touch targets minimum 44px for send button
